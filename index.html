C

C language notes

A C program starts in main(). Use printf to display text and scanf to read input.

#include <stdio.h>

int main(void) {
    printf("Hello, world!\\n");
    return 0;
}

Linux notes

Use a terminal command to work with files and folders. Start by checking where you are.

pwd        # show current folder
ls         # list files
cd notes   # open a folder
mkdir lab  # make a folder
Next: cp, mv, cat, grepStarter note

C language practice questions

Try each problem in your own editor before opening the hint.

1. Read two numbers and print their sum.

Hint: declare two integers, read them with scanf, then print a + b.

2. Check whether a number is even or odd.

Hint: use the remainder operator. A number is even when number % 2 == 0.

3. Print the numbers from 1 to n.

Hint: read n, then use a for loop that counts from 1 through n.

4. Find the factorial of a positive integer.

Hint: start a result variable at 1 and multiply it by each number from 1 to the input.

5. Find the largest value in an integer array.

Hint: begin with the first element as the largest, then compare each remaining element.

6. Make a function that converts Celsius to Fahrenheit.

Hint: use F = C × 9 / 5 + 32. Choose float if you want decimal values.

Quick MCQs

Open each question to check the answer after you try it.

Which function is the usual starting point of a C program?

Answer: main(). Execution of a standard C program begins there.

Which HTML element creates a hyperlink?

Answer: <a>. Its href attribute holds the destination.

Which Linux command shows the current directory?

Answer: pwd. It prints the working directory path.
